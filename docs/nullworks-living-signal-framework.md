# NULLWORKS LIVING SIGNAL FRAMEWORK — LOCKED PATTERN

**Status:** SAVED / STAMPED / EARMARKED / LOCKED

## Core architecture

1. Fixed atmospheric canvas behind the page.
2. One theme-specific scanner or signal language.
3. Rare events that carry system meaning.
4. Structured translucent content above the motion.
5. Foreground copy and controls remain stable.
6. Mobile performance target: approximately 30 FPS with restrained object counts.
7. Reduced-motion mode must preserve the full informational page.
8. Simulated visual atmosphere must never be presented as real telemetry unless a live source is actually connected and labeled.

## Locked doctrine

- The motion must explain the system, not merely decorate it.
- One primary motion language per page.
- Rare events remain rare enough to feel discovered.
- The scanner reveals; objects do not glow continuously without reason.
- Failure, waiting, expiration, escalation, and abstention are valid visual states.
- The human operator remains visually and operationally central when authority is part of the story.
- Content readability outranks animation intensity.
- Never fake a live dashboard.
