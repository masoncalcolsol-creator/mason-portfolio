Status: CANONICAL
Date: 2026-08-29
Canonical domain: https://nullworks.systems

## Purpose

The application repository contains years of prototypes, experiments, music, field tools, private workrooms, research releases, and corporate pages. Repository existence does not equal corporate navigation.

This document separates the public NULLWORKS company from the laboratory beneath it.

## Invariant

A route may exist without being part of the corporate information architecture.

Only routes deliberately promoted into the corporate graph may appear in global corporate navigation or the sitemap.

Private and reviewer routes are never promoted by accident.

## Global Navigation v1

The persistent corporate quick navigation is intentionally small:

`Architecture → Systems → Proof → Research → Company`

Audience doors such as Japan and transactional/service routes such as Triage and Pricing belong inside the relevant corporate pages, not in the persistent identity bar.

## Search / Index Policy

The sitemap is an allowlist, not an automatic dump of application routes.

Robots exclusions cover known private/control surfaces. This is not a confidentiality mechanism.

## Change Rule

For every new route, assign a tier before linking it globally.

Promotion requires answering:

1. Is this corporate truth, a capability, evidence, an audience door, private work, laboratory history, or unrelated content?
2. What canonical page owns the concept?
3. Should search engines discover it?
4. Should global navigation expose it?
5. Does it contain names, relationships, customer/employer details, or claims requiring publication review?

This prevents the repository from becoming the website merely because humans kept making pages, a surprisingly persistent failure mode of our species.
