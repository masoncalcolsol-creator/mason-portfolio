# UMBRA EMS-001 // Dynamic Priority Corridor

Status: CANONICAL PILOT SPEC v0.1
Mode: SHADOW FIRST

## Research question

Can governed orchestration of existing traffic infrastructure reduce emergency vehicle travel friction and travel time while preserving intersection safety and minimizing network disruption?

## Pilot boundary

- one authorized EMS vehicle
- one defined corridor
- finite approved intersections
- one destination or termination condition
- no direct controller writes in Shadow Mode
- municipal traffic engineering retains controller authority
- every proposed and executed action must be receipted

## Mission object

A mission binds:

- mission_id
- requesting organization
- authenticated vehicle identity
- emergency authority state
- start time / expiry
- vehicle position, heading, velocity
- approved route/corridor
- destination
- participating infrastructure
- applicable policies
- observation sources
- abort/revocation state

## Capability model

UMBRA never asks for `MAKE_LIGHT_GREEN`.

The abstract capability is:

`CREATE_SAFE_PRIORITY_ENVELOPE(mission, corridor_segment, time_window)`

An intersection adapter translates that bounded request into whatever operations the approved local traffic system supports. Device-native safety sequencing remains authoritative.

## Moving envelope

For each participating intersection, UMBRA assigns one state:

- NORMAL
- OBSERVE
- PREPARE
- DRAIN
- PROTECT
- RELEASE
- RECOVER
- ABORT

The envelope advances according to vehicle ETA, route confidence, intersection state, queue observations, policy, and safety constraints.

## Shadow Mode

Shadow Mode MUST NOT write to traffic infrastructure.

For every proposed action it emits a `WOULD_REQUEST` event containing:

- mission_id
- intersection_id
- proposed capability
- reason
- predicted vehicle ETA
- policy decision
- constraints evaluated
- timestamp
- confidence/uncertainty
- expected effect

This allows historical replay and live observation before any control authority is granted.

## Metrics

Primary:

- total EMS corridor travel time
- emergency vehicle full stops
- seconds below defined movement threshold
- intersection delay experienced by EMS vehicle
- safety interventions / aborts

Network impact:

- queue length by approach
- conflicting traffic observations
- maximum induced delay
- queue recovery time
- time to normal signal/network state

Derived metric:

### Emergency Vehicle Friction (EVF)

A composite measure of transportation-network resistance encountered by the authorized emergency vehicle. Initial components should include stopped time, low-speed time, intersection delay, route obstruction, and forced evasive/conflict events. The exact formula remains experimental and must be reported alongside its component metrics rather than presented as an unexplained score.

## Evidence synchronization

Preferred synchronized sources:

- UMBRA event stream
- UMBRA receipts
- vehicle GNSS/GPS
- dispatch timestamps where authorized
- traffic-controller logs
- intersection/road sensors
- municipal traffic data
- ground video
- authorized UAS observation

All evidence must use a common time basis or retain enough clock metadata to reconstruct offsets.

## Safety invariants

- Shadow Mode has zero actuation authority.
- Loss of authorization invalidates the mission.
- Mission expiry invalidates priority authority.
- Route ambiguity beyond policy threshold prevents progression of the envelope.
- Local controller safety logic is never bypassed.
- Human municipal/incident authority can revoke the mission.
- Failure of UMBRA must degrade toward ordinary infrastructure operation, not an uncontrolled priority state.
- AI recommendations never independently override deterministic policy or controller safety constraints.

## Experimental ladder

0. Synthetic corridor + simulated ambulance.
1. Historical GPS/traffic replay.
2. Live ambulance/vehicle telemetry in Shadow Mode.
3. Closed-course controller/HIL test.
4. Single intersection approved actuation.
5. Multi-intersection approved corridor.
6. Operational single-ambulance municipal pilot.

## Success criterion

The pilot is successful only if it produces auditable evidence about BOTH EMS benefit and surrounding-network/safety effects. Faster ambulance travel without defensible safety and disruption measurements is not sufficient.
