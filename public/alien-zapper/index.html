How target codes work

Each printed target carries a stable NULLWORKS target URL. The app recognizes the target ID, places a cartoon alien over it, and checks whether the center reticle is inside that target when you say “pew” or press FIRE. The target cards are reusable; the software changes which aliens are friendly or mischievous each round.
