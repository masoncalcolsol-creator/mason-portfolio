# NULLWORKS Portfolio

This repository is the public presentation, field-note, and demonstration layer for Mason Perry / NULLWORKS.

Production site:

`https://mason-portfolio-main.vercel.app`

## Public-by-intent boundary

Material committed here is intended for public inspection and deployment. The repository may contain approved field notes, sanitized demonstrations, public operating-model descriptions, visual systems, and portfolio code.

It is not the canonical store for:

- credentials, tokens, recovery material, or private environment files;
- customer, partner, government, employee, or reviewer confidential information;
- unpublished manuscripts or complete internal architecture;
- private decision receipts, pricing, legal strategy, contract drafts, or commercial negotiations;
- private telemetry, source evidence, or the NULLWORKS Corporate WiFi Hive.

Those materials are maintained in controlled private systems. Public pages should explain what NULLWORKS does without exposing the complete internal machinery required to reproduce it.

## Human authority

Mason Perry remains the final publication and deployment authority. Automated systems may assist with analysis, implementation, verification, and receipts, but they do not independently authorize disclosure or commercial commitments.

## Development

Install dependencies and run the local development server:

```bash
npm install
npm run dev
```

Before opening a pull request, confirm that the change is public by intent, contains no confidential partner or customer information, includes no live credentials, and preserves the stated truth boundaries.

## Security

Report suspected vulnerabilities privately using the process in [`SECURITY.md`](./SECURITY.md). Do not place secrets or exploit details in public issues.
