# Live Learning Forest — Lexicon Leaf Doctrine

## Core distinction

An unfamiliar word does not automatically deserve a full canonical learning page.

- **Lexicon Leaf:** a lightweight, in-context dictionary and thesaurus explanation.
- **Canonical Tree:** a governed subject record with claims, sources, revisions, disputes, and meaningful branches.

## Routing rule

Define the word in the Lexicon Leaf. Grow a Tree only when the concept warrants history, evidence, competing claims, source genealogy, or meaningful conceptual branches.

## Truth boundary

A missing lexical entry creates a lexical-review receipt. It does not create an invented definition, silently plant a canonical topic, or modify an existing tree.
